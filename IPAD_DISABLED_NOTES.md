# iPad Support Disabled

## What Changed

**app.json:**
- Changed `"supportsTablet": true` → `"supportsTablet": false`

## What This Means

### ✅ Benefits:
- **No iPad screenshots required** - Apple won't ask for iPad screenshots
- **Simpler submission** - Only need iPhone screenshots
- **Faster review** - One less thing to manage

### ⚠️ Trade-offs:
- **App is iPhone-only** - Won't be optimized for iPad
- **iPad users can still install** - But app runs in iPhone compatibility mode (scaled up, not optimized)
- **Smaller market** - Some iPad users prefer native iPad apps

### 📱 How It Works:
- iPad users can still download and use your app
- App will run in iPhone compatibility mode (letterboxed/scaled)
- Not ideal for iPad users, but functional

## For This App:
- Since it's a fitness/workout tracking app, iPhone-only is perfectly fine
- Most users will use it on iPhone anyway
- You can always enable iPad support later if needed
