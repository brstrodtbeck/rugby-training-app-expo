# Apple 2FA Authentication - What to Do

## Current Step

You're at the two-factor authentication prompt. EAS is asking how you want to receive your 6-digit code.

## What to Do

**Type either:**
- `device` - if you want the code sent to your Apple device (iPhone, iPad, Mac)
- `sms` - if you want the code sent via text message

Then press Enter.

## After You Choose

1. **If you choose "device":**
   - Check your iPhone, iPad, or Mac for the 2FA popup
   - It will show the 6-digit code
   - You can also find it in Settings > [Your Name] > Sign-In & Security

2. **If you choose "sms":**
   - Check your phone for a text message from Apple
   - It will contain the 6-digit code

3. **After you receive the code:**
   - EAS will prompt you to enter it
   - Type the 6-digit code and press Enter

## Recommended Choice

- **"device"** is usually faster if you have an Apple device nearby
- **"sms"** works if you don't have your Apple device handy

## Once You Enter the Code

The iOS build will continue and both builds will proceed in parallel!
