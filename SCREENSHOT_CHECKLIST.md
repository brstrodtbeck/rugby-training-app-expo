# Screenshot Checklist

## What Screenshots Do You Need?

### Google Play Store

**Phone Screenshots:**
- [ ] At least 2 screenshots (up to 8)
- [ ] Size: 1080 x 1920px (16:9) or 1080 x 2340px (19.5:9)
- [ ] Show key features

**Feature Graphic:**
- [ ] Size: 1024 x 500px
- [ ] Banner-style image
- [ ] App name + tagline/feature

### iOS App Store

**iPhone Screenshots:**
- [ ] At least 3 screenshots
- [ ] Size: 1290 x 2796px (for 6.7" display)
- [ ] Or other required sizes

---

## Screenshots to Take

**Recommended screenshots:**

1. **Home/Dashboard Screen**
   - Shows main app interface
   - Programs/sessions overview

2. **Active Workout Screen**
   - Shows exercise tracking
   - Sets, reps, weight display

3. **Progress/Analytics Screen**
   - Charts, graphs, statistics
   - Progress over time

4. **Readiness Score Screen**
   - If you have a nice UI for this

5. **Exercise History**
   - Shows tracking features

6. **Program Selection**
   - Shows available programs
