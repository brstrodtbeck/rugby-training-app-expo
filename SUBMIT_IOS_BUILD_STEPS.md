# Submitting iOS Build - What to Select

## Current Prompt

EAS is asking how you want to submit your iOS build. Since you already have a completed build, here's what to do:

## What to Select

**Use the arrow keys** to select:
**"Select a build from EAS"** (first option, should be highlighted)

Then press **Enter**.

## What Happens Next

After you select "Select a build from EAS":

1. EAS will show you a list of your recent builds
2. You'll see your iOS build from earlier (the one that finished)
3. Select that build
4. EAS will upload it to App Store Connect/TestFlight

## Alternative Options (Don't Use These)

The other options are for different scenarios:
- **"Provide a URL"** - if you have a direct download URL
- **"Provide a path"** - if you downloaded the .ipa file locally
- **"Provide a build ID"** - if you know the specific build ID

Since your build is already on EAS servers, "Select a build from EAS" is the easiest!

---

## Action

1. **Use arrow keys** to move to **"Select a build from EAS"** (should already be selected/highlighted)
2. **Press Enter**

This will show your available builds and you can pick the iOS one!
